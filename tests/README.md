# Сценарии на Playwright

Каждый файл — самостоятельный сценарий: открывает игру в браузере, играет и проверяет результат. В настоящую базу ничего не пишется: Supabase подменён, отключён или (в `test_live.py`) открыт только на чтение.

```bash
pip install playwright && python -m playwright install chromium
python3 -m http.server 8765      # из корня репозитория, в отдельном терминале
cd tests
python3 test_login.py            # вход по имени и ПИН
python3 test_online.py           # онлайн через BroadcastChannel
python3 test_peer_rejoin.py      # настоящий PeerJS: призрак и вторая вкладка не занимают комнату (нужен интернет)
python3 test_turn.py             # ретранслятор: ключи от функции turn, без неё — напрямую, сбой сети назван честно (нужен интернет, около минуты)
python3 test_peer_lobby.py       # настоящий PeerJS: вход через лобби — карточка не прыгает под курсором, двойной клик, двое жмут одну комнату
python3 test_training.py         # тренировка с многоволанкой (идёт пару минут)
python3 test_length.py           # длина партии «до 7 / до 15», в сети её задаёт хозяин
python3 test_ai_balance.py       # баланс ИИ на ускоренной симуляции и однообразные боты (пара минут)
python3 test_ai_smart.py         # умный ИИ: читает однообразного, с разнообразным — как сложный (около трёх минут)
python3 test_kill.py             # добивание у сетки: какой удар выходит, высота сетки над тросом, ИИ добивает (около минуты)
python3 test_net_stats.py        # сводка сети уходит с матчем от обеих сторон; путь через настоящий ретранслятор Cloudflare (нужен интернет)
python3 test_news.py             # «Что нового»: окно при входе только вернувшемуся, пункт с анимацией и назад к списку; таблица на 21 игрока
```

База — схема и миграции в PGlite (настоящий Postgres в WebAssembly) под ролью `anon`, как у игры с публичным ключом: прямая запись закрыта, `bdm_sync` / `bdm_room` пишут только своё, перебор ПИНа блокируется. Второй прогон накатывает миграцию на старую схему по шагам:

```bash
cd tests/db && npm install && npm test
```

После деплоя — проверка живого сайта, локальный сервер не нужен:

```bash
cd tests && python3 test_live.py
```

Она читает настоящую Supabase (любая запись обрывается и роняет тест), соединяет два браузера через настоящий PeerJS, доигрывает матч против ИИ и проверяет, что настоящая база не даёт писать напрямую. Пробы ничего не записывают даже в открытую базу: строки заведомо кривые, фильтры ни с чем не совпадают.

Переменные окружения:
- `BASE_URL` — другой адрес локальной игры (если 8765 занят: `BASE_URL=http://127.0.0.1:8766/index.html`)
- `CHROME` — путь к своему Chrome вместо Chromium от Playwright (на Маке: `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`)
- `LIVE_URL` — другой адрес для `test_live.py`, `SHOTS` — папка для его скриншотов
- `SECS` — игровых секунд на случай в `test_ai_balance.py` и `test_ai_smart.py`, `HTML` — подставить другую версию `index.html` (сравнить со старым коммитом: `git show <коммит>:index.html > /tmp/old.html && HTML=/tmp/old.html python3 test_ai_balance.py`)

## Однообразный соперник (замер 18.11.2026, по 24000 игровых секунд на случай)

Бот на физике сложного (`ai.bot`) всегда жмёт одну кнопку с одним прицелом. До 18.11 такой бот обыгрывал сложного: средний и сложный под давлением отвечали свечой или клиром, а высокий волан давления не создаёт и почти не снимает. Давящий соперник (дроп, сетка, смэш) копил давление на ИИ (в среднем 0,56 против 0,28 у бота), качество ударов ИИ падало, и его добивали.

Тактика (`tact` в `DIFFS`, у среднего, сложного и умного, у лёгкого нет): под давлением ИИ реже поднимает волан (вес свечи и клира × (1 − давление), у сетки × (1 − 1,5 · давление)). У сетки снизу он в 90% бьёт тугую сетку, а в защите от смэша, пока соперник сзади, вместо свечи чаще ставит блок или драйв. Физика, скорость и сила не менялись.

| Бот против сложного | Очки у сложного, до | после | Партии у сложного, до | после |
|---|---|---|---|---|
| острый дроп / тугая сетка | 44,0% | 52,3% | 26% | 64% |
| дроп в середину | 60,0% | 72,7% | 81% | 99% |
| длинный дроп | 60,3% | 73,5% | 80% | 99% |
| смэш в ноги (снизу драйв) | 51,7% | 75,8% | 56% | 100% |
| смэш (снизу драйв) | 44,0% | 69,3% | 25% | 99% |
| смэш на заднюю (снизу драйв) | 32,9% | 57,8% | 2% | 82% |
| атакующий клир | 84,7% | 84,6% | 100% | 100% |
| глубокий клир | 74,2% | 77,0% | 100% | 100% |
| случайный бот (любая кнопка, любой прицел) | 61–65% | 73,1% | 89–95% | 100% |
| хитрец: случайная привычка на 45 с | 53,0% | 72,3% | | |

- Тактика сделала ИИ сильнее не только против однообразных, но и против разнообразной игры: против случайного бота сложный набирает 73% вместо 62–65%. Против среднего у него 62%, как раньше, потому что тактика есть у обоих.
- `test_ai_balance.py` гоняет трёх однообразных ботов: дроп ≥ 55% очков у сложного, смэш на заднюю ≥ 50%, смэш в ноги ≥ 55% — и «человека»-дропера: не больше 60% очков против сложного.

**Живой игрок был сильнее бота: у него не было случайных срывов.** Срыв (`fail()` в `doHit`) бывал только у ИИ (`err`), человек ошибался лишь от плохого контакта. Тугая сетка (запас 1,5 см) и острый дроп для него были почти без риска. Профиль «человек» в тестовом замере: `DIFFS.human = { react: 0.22, speed: 1, spread: 1, err: 0, perfect: 0.35, … }`, бег и точка удара как у ИИ.

| «Человек» без риска против ИИ | Очки у сложного, до тактики | после | Очки у среднего, до тактики | после |
|---|---|---|---|---|
| всегда острый дроп | 12,6% | 25,0% | 9,1% | 27,6% |
| всегда смэш в ноги | 43,4% | 68,4% | 22,1% | 41,1% |
| случайные удары | 48,3% | 67,1% | 33,4% | 46,4% |

Тот же дропер с `err` как у сложного набирал против него 40%, как бот: всё решали срывы. Против дропера сложный проигрывал 36% розыгрышей своей же тугой сеткой в трос, а у человека тугая сетка не срывалась никогда. Реальных матчей с ИИ в базе пока шесть: один игрок обыграл сложного 3 раза из 3 с 69% очков.

### Риск тугого прицела у живого игрока — не выкатили

Срыв тугого прицела (`slip`, `TIGHT_RISK = 0.45`: тугая сетка и острый дроп иногда уходят в трос, глубокий клир — в аут) мерили 18.11.2026 в ветке `wip/tact-slip`: «человек»-дропер против сложного 74 → 49% очков. В сборку его не взяли (решение Кирилла 18.11): он наказывает случайно за правильно нажатый удар. Вместо него — добивание у сетки (ниже). Замеры срыва — в истории ветки `wip/tact-slip`.

## Умный ИИ (замер 18.11.2026, по 24000 игровых секунд на случай)

Физика у умного та же, что у сложного, разница только в чтении: он копит, каким ударом и куда соперник отвечает в похожей ситуации, и при уверенном прогнозе ждёт до 0,9 м ближе к нужной точке. Соперники — боты на физике сложного (`ai.bot` в `_util.ai_case`): однообразный всегда жмёт одну кнопку с одним прицелом, случайный — любую кнопку и любой прицел.

| Соперник (стиль «Техника») | Очки у сложного | Очки у умного | Разница | «Читаю тебя» |
|---|---|---|---|---|
| средний ИИ | 63,5% | 62,8% | −0,7 | в 25% розыгрышей |
| случайный бот | 73,1% | 74,3% | +1,2 | в 2% |
| однообразный: острый дроп / тугая сетка | 51,7% | 65,4% | +13,7 | в 97% |
| однообразный: глубокий клир | 77,0% | 76,0% | −1,0 | в 98% |
| однообразный: смэш (снизу — драйв) | 69,3% | 68,8% | −0,5 | в 19% |
| однообразный: смэш на заднюю | 57,8% | 62,6% | +4,8 | |
| хитрец: случайная привычка на 45 с | 72,3% | 69,3% | −3,0 | |
| хитрец: случайная привычка на 20 с | 70,9% | 68,7% | −2,2 | |

Цифры после тактики 18.11 (раздел выше). До неё: дропер 39,7 → 57,2% (+17,5), смэш 44,2 → 45,0%, против среднего 64,6 → 62,5%.

- С разнообразным соперником умный играет как сложный. Против случайного бота он уверен в 4% ударов и угадывает половину. Средний с тактикой стал предсказуемее: умный уверен в 21% его ударов и угадывает 73%, но очков это не прибавляет.
- Дропера сложный теперь держит на грани (52% очков, 56–69% партий), умный выигрывает у него 95% партий: чтение по-прежнему главный выигрыш умного.
- Против смэша чтение не помогает: смэш долетает за 0,4 с, и решает качество приёма, а не то, где ИИ стоял.
- Хитрец, который держит одну привычку и меняет её, наказывает умного чуть сильнее, чем сложного: тот уверенно встаёт не туда. Так и задумано — игрок может обмануть, меняя удары.

`test_ai_smart.py` проверяет то же: сравнения «как сложный» на 30000 с (шум разницы около 1,6 п.п.), однообразного — на 15000 с: против среднего и случайного умный не сильнее сложного больше чем на 5 п.п. и не слабее больше чем на 8, против однообразного дропера он сильнее на 8 п.п. и больше (после тактики около +14). Плюс игра через меню: «Читаю тебя» появляется, память лежит в `bdm-read` и переходит в следующую партию, матч записан с уровнем `smart` и уходит в общую таблицу, а если база ещё без миграции `20261118_smart_level.sql` и пропустила его — остаётся в очереди и уходит со следующей синхронизацией. Сама миграция проверяется в `tests/db` (оба режима: схема целиком и старая схема → миграции по шагам).

## Добивание у сетки без тактики (замер 18.11.2026, до и после)

Смэш по волану у сетки, который идёт выше троса, теперь бьёт коротко и вниз (`kill`). Вместе с ним сетка получила точный угол (с шагом 2,5° «тугая» шла на 15–50 см над тросом), сетка из-под пола выходит выше, а ИИ после своей сетки ждёт в 2 м от неё, а не в 3,3. Замер на версии без тактики `tact` и срыва `slip`: «до» — цифры 17.11, «после» — `test_ai_balance.py` (15000 с на случай) и `test_ai_smart.py`.

| Случай (стиль «Техника») | До | После |
|---|---|---|
| средний — средний: очки слева / ударов за розыгрыш | 51% / 11,9 | 49% / 11,1 |
| сложный — средний: очки / партии слева | 62% / 81 из 89 | 64% / 46 из 48 |
| средний — сложный: очки / партии слева | 37% / 10 из 91 | 39% / 4 из 49 |
| лёгкий — средний: очки / партии слева | 22% / 0 из 138 | 26% / 0 из 63 |
| сложный «Защита» — средний «Атака» | 61–71% | 68% / 49 из 49 |
| средний ИИ: очки у сложного / у умного | 64,6% / 62,5% | 64,4% / 62,3% |
| случайный бот: очки у сложного / у умного | 61,6% / 61,5% | 62,4% / 60,3% |
| однообразный дропер: очки у сложного | 39,7% (проигрывает 3 из 4) | 53,0% (выигрывает 62% партий) |
| однообразный дропер: очки у умного | 57,2% | 88,1% (все 123 партии) |

- Уровни и стороны не сдвинулись, разница в пределах шума.
- Дыру с дропером закрыло в основном то, что ИИ после своей сетки остаётся у сетки: ответ сеткой он берёт выше и раньше. Сами добивания в игре ИИ против ИИ редкие (0,1–0,3% ударов): ИИ реагирует с задержкой и редко стоит у троса, когда волан над ним. Умный стоит — он заранее знает, что придёт дроп, — поэтому дропера он громит.
- Побочный эффект точного угла: тугая сетка с нечистого контакта чаще цепляет трос. У среднего против среднего розыгрышей, закончившихся сеткой в трос, стало 18% вместо 13,5%.
