# Смэш мне в ногу

Бадминтон в браузере, вид сбоку, одиночка до 15. Волан летит по физике с квадратичным сопротивлением воздуха.

Играть: https://smash-v-nogu.github.io/

- **Против ИИ** — три уровня сложности, ИИ отвечает на реакции.
- **Тренировка с многоволанкой** — робот подаёт 20 воланов, клади их в подсвеченные зоны; общая таблица рекордов.
- **Онлайн с другом**: комната по коду из 4 символов или из списка «Ждут соперника». Соединение напрямую через WebRTC (PeerJS), реакции на 1–4.
- **Аккаунты**: имя + ПИН из 4 цифр, чтобы играть с телефона и разных браузеров под одним профилем.
- **Общая таблица побед** (Supabase): победы–поражения с друзьями и против ИИ, рекорды смэша, кубки за первые три места.
- **Механики розыгрыша**: выносливость, чистый удар по таймингу, выбор глубины удара, стиль игры (атака / техника / защита), инициатива.
- **Ястребиный глаз**: после розыгрыша на полу видно, куда упал волан и насколько близко к линии.

Управление: `A`/`D` бег, `W` прыжок, `Q` клир, `E` дроп, `S` смэш, `1`–`4` реакции, `Esc` пауза.

## Разработка

- Всё в одном файле `index.html`, сборки нет. Локально: `python3 -m http.server 8765` и открыть http://localhost:8765/
- Устройство кода, база и подводные камни — в `CLAUDE.md`
- Схема базы — `supabase/schema.sql`
- Сценарии на Playwright — `tests/`
- Идеи — `docs/IDEAS.md`
- Деплой: пуш в `main`, GitHub Pages обновится сам
